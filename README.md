# 🍳 CookMate – "Your Smart Recipe Companion"

CookMate is a smart recipe web application that helps you discover delicious meals using the ingredients you already have at home. Whether you’re short on time, want to try something new, or just need dinner ideas, CookMate has you covered.

Simply enter your ingredients, and CookMate will instantly fetch matching recipes from TheMealDB API.

🌐 Live Demo
👉 Click here to try CookMate (https://cookmate-app.vercel.app/)

## ✨ Features

- **🔍 Ingredient-Based Search**: Find recipes based on what you already have in your kitchen.
- **📖 Recipe Discovery**: Explore dishes with detailed instructions, images, and even YouTube tutorials.
- **⚡ Quick & Easy**: Perfect for busy professionals like Taylor, who want smart cooking help after work.
- **📱 Responsive Design**: Works smoothly on desktop, tablet, and mobile.
- **🎨 Modern UI**: Clean, user-friendly, and visually engaging.

## 🛠️ Technologies Used

- **⚛️ React.js**: For building the interactive UI.
- **🎨 CSS**: For styling and layout.
- **🍲 TheMealDB API**: As the recipe data source.

## 🚀 Getting Started

Follow these steps to run CookMate locally 👇

### Installation

1. Clone the repository:
   ```
   git clone <repository-url>
   cd cookmate
   ```

2. Install dependencies:
   ```
   npm install
   ```

3. Start the development server:
   ```
   npm start
   ```

4. Open your browser at 👉 http://localhost:3000.

## 🔑 API Used
I use TheMealDB API for fetching recipes.

Example endpoint:
https://www.themealdb.com/api/json/v1/1/filter.php?i=chicken

## 🎯 Usage

1. Enter ingredients in the input field and click "Add".
2. Click "Search Recipes" to fetch recipes from TheMealDB.
3. Browse recipe cards → view full instructions, ingredients list, and cooking video.
